🍎 iPhone 安装方法（无需电脑 / 无需商店）

必须用 Safari。如果这个链接是在 WhatsApp 或微信里打开的，那里没有“添加到主屏幕”这个按钮：先点右上角 ··· → 在浏览器中打开，或长按链接复制网址，再打开 Safari 粘贴。

  1. 用 Safari 打开 https://campus-connect-qticqalyo1y.qoder.website，先登录一次（登录会被记住，下次不用重登）。
  2. 点页面下方的 分享按钮（方框 + 向上箭头 ↑）。
  3. 向下滚动，点 “添加到主屏幕”。
  4. 名称会显示为 campus connect（你可以改成想要的名字），点 “添加”。
  5. 主屏幕会出现 🎓 图标，点开即是全屏 App（没有浏览器地址栏），断网也能读到已缓存的聊天。
  6. 以后不用重装：我更新网站后，你下次打开图标就自动是最新版；已经装过的同学也会自己升级。

实话实说的限制：① App 关掉之后不会响——后台推送还没接通（安卓版也一样），要收到消息得先打开过它；② 个别功能取决于 iPhone 的网页引擎，比如通话要用 Safari 允许麦克风；③ iOS 16.4 以下的手机不支持网页通知。数据与 Android、网页版完全互通，一个账号到处能用。

🍎 Install on iPhone (no computer, no store)

It has to be Safari. If you opened this link inside WhatsApp or WeChat, that browser has no “Add to Home Screen” button: tap ··· → Open in browser, or long-press the link to copy it and paste it into Safari.

  1. Open https://campus-connect-qticqalyo1y.qoder.website in Safari and sign in once — it remembers you next time.
  2. Tap the Share button (box with an up arrow ↑) at the bottom of the page.
  3. Scroll down and tap “Add to Home Screen”.
  4. The name shows as campus connect (rename it if you like) — tap Add.
  5. A 🎓 icon appears on your Home Screen — it opens as a full-screen app with no browser bar, and your saved chats still read without network.
  6. No reinstalling later: when I update the site, the icon opens the new version by itself.

Honest limits: ① it does not ring while closed — background push is not connected yet (same on Android), so open it to catch up; ② a few features depend on the iPhone web engine — a call needs Safari to allow the microphone; ③ iPhones on iOS 16.4 or older get no web notifications at all. One account works across iPhone, Android and the website.

安装步骤（Android）

  1. 点击上方按钮下载 campus-connect.apk。
  2. 浏览器弹出安全提示时，选择 “仍要下载 / 保留文件”。
  3. 打开“文件管理”里的下载文件，点击安装。
  4. 首次安装会提示 “未知来源应用”：进入 设置 → 应用 → 特殊应用权限 → 安装未知应用，允许你使用的浏览器安装，然后返回重试。
  5. 安装完成后打开应用，用你的 已批准账号 登录即可（如果数据库迁移还没执行，管理员功能会暂时不可用）。

How to install

  1. Tap the download button above to get campus-connect.apk.
  2. If the browser shows a security warning, choose “Download anyway / Keep file”.
  3. Open the file in your Downloads folder and tap Install.
  4. On first install, Android asks about “Unknown apps”: go to Settings → Apps → Special app access → Install unknown apps, allow your browser, then retry.
  5. Launch the app and sign in with your approved account.
