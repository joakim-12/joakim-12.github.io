安装步骤（Android）

  1. 点击上方按钮下载 Campus-Connect-v2.05-Android.apk。
  2. 浏览器弹出安全提示时，选择 “仍要下载 / 保留文件”。
  3. 打开“文件管理”里的下载文件，点击安装。
  4. 首次安装会提示 “未知来源应用”：进入 设置 → 应用 → 特殊应用权限 → 安装未知应用，允许你使用的浏览器安装，然后返回重试。
  5. 安装完成后打开应用，用你的 已批准账号 登录即可（如果数据库迁移还没执行，管理员功能会暂时不可用）。

How to install

  1. Tap the download button above to get Campus-Connect-v2.05-Android.apk.
  2. If the browser shows a security warning, choose “Download anyway / Keep file”.
  3. Open the file in your Downloads folder and tap Install.
  4. On first install, Android asks about “Unknown apps”: go to Settings → Apps → Special app access → Install unknown apps, allow your browser, then retry.
  5. Launch the app and sign in with your approved account.

FAQ

  • Will it install over my old app? It updates builds signed with the same key. If Android reports a signature conflict, use the original signing key for that installation; uninstalling first can erase phone-only app data.
  • How do I update? Return to this page and install a newer APK signed with the same key. Your account data remains on the server.
  • iPhone? Yes — open the site in Safari and tap Share → Add to Home Screen. See the iPhone section above.
