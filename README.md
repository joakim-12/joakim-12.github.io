# Campus Connect

This repository contains the ready-to-publish Campus Connect website at its root.
The `downloads` folder contains the iPhone project source ZIP.

## GitHub Pages
The repository root contains `index.html`. On GitHub Free, the repository must be public to publish with GitHub Pages. Private repositories require a plan that supports private Pages. Once available, publish from the `main` branch using the `/(root)` folder.

## iPhone
After the website is online, open its URL in Safari and choose Share > Add to Home Screen.
